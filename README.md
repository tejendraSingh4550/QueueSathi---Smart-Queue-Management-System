# QueueSathi

A compact, offline Java Swing queue manager for clinics, salons, and service desks.

## Run

Requires Java 17 or newer. Open a terminal in this folder:

    javac -encoding UTF-8 QueueSathi.java
    java QueueSathi

Add visitors, search the queue, call the next waiting visitor, and mark visits complete. Data is saved locally in queuesathi-data.csv.
